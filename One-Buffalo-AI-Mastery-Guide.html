3. Executive Prompting Blueprints for Antigravity

Adopt these four battle-tested prompting patterns when collaborating with Antigravity:

Pattern 1: The Contract-First (Spec-Driven) Prompt

Rather than describing line-by-line coding steps, define the strict contract, data invariants, and verification criteria:

Goal: Add an NHL tiebreaker matrix to `sabres.html`.

Contract & Invariants:
1. Inputs: Reads from `data.json` under `sabres.tiebreakers`.
2. Output: Render a 3-column responsive flex grid (#1 Seed, Wildcard 1, Wildcard 2).
3. Invariant: Vanilla CSS only. Do not add external CDNs or JS libraries.
4. Verification: Run `npm test` and assert all 4 audit suites pass.

Pattern 2: The Self-Correcting Test Loop Prompt

Leverage Antigravity's terminal execution capability by instructing it to run in a test-verification loop:

Goal: Fix the overtime time-decay anomaly in `calculateLiveNhlWinChance`.
Action Loop:
1. Add a failing unit test in `test/audit_stats.js` for an OT scenario (0-0 score, 1:30 left in OT).
2. Edit `scripts/scrape.js` to fix the decay curve.
3. Run `npm test` autonomously until the test passes.
4. Report the mathematical diff.

Pattern 3: The Architectural Interrogation

Before letting the agent write hundreds of lines of code, force it to challenge your assumptions and surface hidden edge cases:

"I want to add a push-notification system for live Bills scores. Before writing any code, interview me on my constraints using /grill-me. Challenge my data frequency, battery impact on mobile PWAs, and serverless cost limits."

Pattern 4: Antigravity Slash Commands Reference

  • /plan: Drafts an architectural step-by-step roadmap before files are modified.
  • /grill-me: Triggers an interactive design interview to resolve ambiguities before execution.
  • /boost: Activates multi-perspective deep reasoning for complex mathematical or structural problems.
  • /compact: Compresses conversation history to eliminate context rot and save token capacity.
  • /learn: Persists repository rules and preferred coding standards across sessions.
