# 🦬 One Buffalo Tracker

> Live postseason probabilities, matchup intelligence, and rooting guides for the Buffalo Bills and Buffalo Sabres.

**Live Site:** [https://onebuffalotracker.fyi](https://onebuffalotracker.fyi)

---

## ⚡ Overview

**One Buffalo Tracker** is a high-performance, real-time command center built for Western New York sports fans. It tracks the postseason trajectories of both the **Buffalo Bills** (NFL) and **Buffalo Sabres** (NHL) by pairing Monte Carlo playoff odds with live in-game intelligence, situational leverage calculations, and dynamic rooting guides.

---

## 🌟 Core Features

### 📡 1. Postseason Radar
* **Dynamic Odds**: Real-time probabilities for playoff qualification, division championships, and #1 seed / first-round bye (Bills) or Wildcard berths (Sabres).
* **Clinching & Magic Numbers**: Live AFC East Magic Number countdown and Sabres pace targets (92-point cutoff line), with automatic clinching alerts when scenarios become active.
* **Seed Distributions & 1st Round Opponents**: Percentage breakdowns of potential seedings and live probability matrices for projected first-round playoff matchups.

### 🧠 2. Matchup Intelligence
* **Countdown & Broadcast Intel**: Exact kickoff/puck-drop countdown clocks, TV network badges (CBS, FOX, NBC, Prime Video, ESPN+, MSG-B), broadcast crews, and venue/weather conditions.
* **Playoff Leverage Swing**: Calculates the exact playoff percentage swing for Buffalo under a **Win** vs. a **Loss**.
* **Tale of the Tape**: Efficiency comparisons covering Passing/Rushing Yds, 3rd Down %, Red Zone TD %, Turnover Margin (NFL), and Goals/GP, GAA, Special Teams net differentials (NHL).
* **Dynamic Injury Wire**: Real-time status tags (*Questionable*, *Out/IR*, *Active*, *Starting Goaltenders*).

### 🧭 3. Out-of-Town Rooting Guide & Live Scoreboard
* **Chronological Windows**: Games grouped cleanly by slate (TNF, Early 1:00 PM, Late 4:05/4:25 PM, SNF, MNF, NHL 7:00 PM, West Coast).
* **Live In-Game Score Polling**: Direct client-side polling of ESPN scoreboards (25s intervals during live games, 60s otherwise) without third-party rate limits.
* **Real-Time Buffalo Impact Verdicts**: Dynamically computes Buffalo's rooting interest based on live game states:
  * 🟢 `GOOD FOR BUFFALO (LEAD)`
  * 🔴 `BAD FOR BUFFALO (TRAILING)`
  * 🟡 `TIED • LEVERAGE WATCH`
* **Live Win Probability Meters**: Displays real-time win probability bars for every out-of-town matchup.

### 📱 4. Progressive Web App (PWA) & Offline Resiliency
* **Dual-Layer Fallback**: If offline or if upstream APIs fail, the dashboard falls back to embedded baseline data without throwing errors or breaking the UI.
* **Service Worker (`sw.js`)**: Stale-While-Revalidate caching for instant launch on iOS and Android home screens, with live score API bypass to guarantee scores are never stale.

## 🔄 Data Pipeline & Automation

The data pipeline runs via `scripts/scrape.js`:
1. **PlayoffStatus.com**: Scrapes Monte Carlo simulation odds, division races, and seed distributions.
2. **ESPN Public APIs**: Fetches schedules, team efficiency stats, venues, weather, networks, announcer crews, and injury reports.
3. **Automated Fallback Synchronization**: Whenever `data.json` is updated, `scripts/scrape.js` automatically syncs the embedded `FALLBACK_DATA` blocks inside `index.html`, `bills.html`, and `sabres.html`.
4. **Triggering**: Automated via `cron-job.org` calling GitHub Actions' `workflow_dispatch` endpoint around critical post-game windows.

## 💻 Local Development

### Prerequisites
* [Node.js](https://nodejs.org/) (v18 or higher)

### Setup
```bash
# Clone the repository
git clone https://github.com/olfhq/One-Buffalo-Dashboard.git
cd One-Buffalo-Dashboard

# Install dependencies
npm install

# Run the data scraper manually
npm run scrape

# Run the test and audit suite
npm test
```

### Viewing the Site Locally
Because the project uses standard web technologies, you can open `index.html` directly in your browser or run any lightweight local server:

```bash
npx serve .
```
